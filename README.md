# React Posts & Users Dashboard (SPA) 🚀

A simple and practical React.js training project built to practice working with React Router, REST APIs, CRUD operations, and modern UI styling.

This project uses the JSONPlaceholder API to fetch posts and users and provides a simple interface for managing posts and exploring user information.

🎯 This project was created mainly for learning and practicing React concepts and demonstrating frontend development skills.

## ✨ Features

🏠 Simple Home page with navigation links

🧭 Navigation using React Router

🔗 Active navigation states with NavLink

📝 Display posts fetched from JSONPlaceholder API

➕ Create new posts

✏️ Edit existing posts

🗑️ Delete posts

👤 Display users fetched from JSONPlaceholder API

🔍 View detailed information about each user

🔔 Toast notifications using React Toastify

📱 Responsive UI

🎨 Styled with Tailwind CSS

## 🛠️ Technologies
